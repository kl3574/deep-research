# Zotero corpus workflow (local only)

This skill accepts references to local outputs generated by external Zotero/corpus workflows.

## Input boundaries

- `init` accepts `--snapshot-path` and `--snapshot-digest`.
- Supported path form is local filesystem path only.
- No direct Zotero API calls or library writes.

## Snapshot binding

1. On init, compute SHA-256 over the snapshot file bytes.
2. Require user-provided digest to match exact bytes.
3. Store both canonical path and digest in `network.json`.
4. Recompute during `validate`; mismatch is fail-closed.

## Corpus-safe behavior

- Never ingest from remote/network sources.
- Never dereference symlinks for snapshot and ledger files.
- Reject snapshot path traversal outside the workspace root.
