# v0.8.0 release notes

Evidence cutoff: 2026-08-13

`v0.8.0` is a scoped package-revision release for the public deep-research skill
suite. It adds one additional core skill, hardens multiple audit contracts, and
extends CI coverage so the tree layout and test graph include the new core
runtime-retrospective surface. The release does not claim GitHub tag/release
creation, live Zotero writes, network mutation completion, or installation
completion for any environment.

## Package scope

The default Codex install is now documented as twelve core skills:

1. `deep-research`
2. `learn-from-papers`
3. `evidence-appraisal`
4. `research-knowledge-network`
5. `network-gap-discovery`
6. `scholar-discovery`
7. `scholarly-source-acquisition`
8. `scholarly-document-normalization`
9. `research-workflow-retrospective`
10. `curate-research-to-zotero`
11. `repair-zotero-metadata`
12. `research-network-publish`

The optional companion `zotero-declarative-bridge` remains version `0.1.11` and is
not part of the default install set in this scope.

## Core change set

- `deep-research` now includes explicit runtime controls via
  `references/research-runtime-controls.md` for ambiguous/high-risk/multi-agent/
  mixed-scope work. These plan/effort/domain controls are an operator contract,
  not automatically enforced orchestration. A deterministic
  `ReportCitationAudit/v1` helper is now connected to an opt-in
  `research_run.py init --require-citation-audit` completion gate through a typed,
  raw-hash-pinned, replay-validated audit event.
- `learn-from-papers` and `network-gap-discovery` now use
  `PaperReadingEvidenceCollection/v1` as the multi-paper reviewed evidence bundle.
  `network-gap-discovery` now enforces `ReviewedGapSelection/v2` consumption for
  patching and aligns `propose-patch-v4` proposal sequencing with explicit
  authoring and authorization requirements.
- `research-knowledge-network` strengthened source-aligned scientific mutation
  controls across appraisal binding/projection/plan/acceptance. The
  non-ASCII digest validation path now rejects mutation drift at digest level.
- `evidence-appraisal` accepts the exact learn-from-papers page/character locator
  atom at its owner seam. `research-network-publish` narrowly permits governed
  appraised-mutation `authorization_digest` fields and redacts embedded network
  and snapshot identifiers from public projections.
- `curate-research-to-zotero` now requires `itemType` in bundled parent payloads
  and retains strict projection validation around parent/note/attachment entry
  types.
- `research-workflow-retrospective` is now a first-class public skill used to turn
  hash-bound completed/failed workflow traces into test-ready seam proposals.

## Release boundary

- This document reflects repository-level capability and contract changes only.
- It does not certify that the GitHub release/tag is created, that the code is
  installed across environments, or that live Zotero mutation/readback has been
  completed for any run.
- Runtime controls and report-citation audit behavior remain bounded by the
  skill contracts and their validation steps; they are not universal evidence of
  complete factual correctness, completeness, or review quality.
- Agent-product starter evaluations are synthetic and bounded. Two of three
  local benchmark scenarios completed during development; one Codex evaluation
  was interrupted after exceeding the bounded wait. The separate real-workflow
  retrospective covers five incidents in one domain and is likewise bounded;
  neither result supports a universal benchmark or cross-repository quality
  claim.
