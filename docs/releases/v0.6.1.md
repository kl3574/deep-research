# v0.6.1 release notes

Evidence cutoff: 2026-08-06

`v0.6.1` is a real-scenario hardening release. The driving case used an
existing 45-paper Zotero corpus to investigate DoE, surrogate models and
morphology inverse problems, repair local delivery, publish a persistent
knowledge network, discover open scientific gaps, and then improve the skill
suite from observed failures. This is not a boundary-only audit and not a
systematic review.

## Package scope

The release keeps nine orthogonal research skills and adds the packed
`zotero-declarative-bridge` as an opt-in execution companion. Curation owns
deduplication, approved Zotero writes and readback. Source acquisition owns one
already-selected public PDF. The bridge owns only sealed existing-parent
operations. Discovery candidates never become evidence or graph mutations
without full-text review and governance acceptance.

## Real Zotero delivery

- The bounded private collection finished with 45 parent records, 45 nonempty
  bibliographic short titles, and exactly one nonempty note per parent.
- Forty-two parents have a locally readable PDF. Three remain explicitly
  metadata-only rather than receiving a fabricated attachment claim.
- Twelve PDF imports were committed and read back: one canary and an 11-item
  sequential repair batch. The batch verified 56,361,131 local bytes.
- The run performed no deletions and makes no metadata- or PDF-cloud-sync
  completion claim.

Bridge `0.1.4` performed the live canary and delivery writes. Bridge `0.1.5`
was then installed active in Zotero `9.0.6`, advertised only four allow-listed
operations and two execution profiles, and passed positive readback of the
attachment, metadata and short-title transactions. A real parent outside the
target collection produced `not_applied`, `all_satisfied=false` and
`needs_write`, proving that item existence is not mistaken for target
membership. No duplicate PDF was imported merely to claim an `0.1.5` write.

## Knowledge network and publication

- The current 45-record Zotero snapshot is bound into an append-only network
  containing 423 published nodes.
- Export now projects 196 explicit `claim --about--> entity` relations from
  reviewed `claim.entity_id` fields. Relations increased from 241 to 437,
  isolated domain entities fell from 111/112 to 0/112, and no dangling or
  duplicate relation endpoint was introduced.
- Entity-to-entity semantics are not guessed. The ledger needs an explicit
  evidence-bearing relation schema before such edges can be accepted.
- The final private HTML contains 45 current bibliographic source cards, 42
  DOI-bearing sources and 233 visible gaps. Two independent renders are
  byte-identical, self-contained and browser-load clean.
- Completion remains partial: ten explicit high-priority gaps and eleven
  high-impact claims without decisive evidence remain open.

## Gap-driven discovery

A real open-world cycle selected three scientific gaps and produced twelve
ranked candidates, eight at Tier A. Crossref returned bounded candidates but
also one HTTP 429; anonymous Semantic Scholar routes returned 429; Crossref and
OpenAlex DOI lookups verified the twelve identities. Google Scholar stayed
`not_provided_manual_optional`: no result HTML was scraped and no API result was
relabeled as Scholar evidence. Zero gaps were closed because every candidate
still requires full-text review.

The run exposed two immediately actionable defects that are fixed here:

- scientific `semantic_label` now survives signal, hypothesis and `paper_need`
  projection, while internal `claim:`, `gap:` and `derived:` identifiers and
  template-only phrases are rejected from provider queries;
- manual-optional Scholar rows are emitted for the user but no longer consume
  the autonomous API query budget.

An offline replay of the same network produced 96 semantic labels, 18 paper
needs and 36 query strings, including 16 Unicode queries and zero internal-ID
query leaks.

## Skill and bridge hardening

- `research-knowledge-network` and `research-network-publish` now preserve the
  current Zotero bibliography contract and deterministic claim-to-entity
  relations.
- `curate-research-to-zotero` no longer claims source selection or download
  ownership; missing selected PDFs route to `scholarly-source-acquisition`.
- Zotero snapshot pagination now covers collections with more than 100 parents
  or children and rejects repeated full pages.
- Attachment fallback imports exactly one PDF without an unsafe outer database
  transaction, performs immediate readback, and treats uncertain failures as
  unknown rather than rolled back.
- Bridge `0.1.5` enforces target membership during readback, writes structured
  private `0600` failure receipts, redacts stderr, and rejects mixed or batched
  attachment writes.
- The security-sensitive development proxy installer was removed from the
  stable skill. Packed-XPI installation is the supported route.
- XPI build validation now rejects wrong update URLs, duplicate versions,
  wrong release tags/assets/hashes, and malformed or missing update manifests.

The deterministic packed asset is
`zotero-declarative-bridge-0.1.5.xpi` with SHA-256
`10c0e06c7a7fa85afe73b3a9c49d518d7777513a1d55cb01eb8ed8182d1db76b`.

## Validation and residual limits

The final local tree passed Ruff, the public-tree privacy gate, Python
compilation, all README/CI Python suites, the bridge Node contract, the private
real-run evidence-pack audit, deterministic HTML comparison, and a headless
Chrome load. Plugin-eval found valid frontmatter and zero broken relative links
for all ten skills; its static mean was 77.8/100. Static complexity and deferred
token warnings remain maintenance signals, not evidence of a behavioral defect.

Deferred work remains explicit:

- HTTP 429 retry/backoff and provider-wide rate coordination need a bounded
  execution contract.
- DOI exact-identity closeout and preprint/version-of-record work-family
  grouping need a dedicated schema and validator.
- Crossref auto-match still needs stronger domain and must-not screening.
- Google Scholar remains manual export only.
- Cloud sync, universal literature completeness and closure of the remaining
  scientific gaps are not claimed.
