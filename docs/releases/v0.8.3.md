# v0.8.3 release notes

Evidence cutoff: 2026-10-13

This release adds bounded primary-source investigation and clearer delegation
to three research skills. It preserves the twelve-skill default package and
the transactional installation, academic evidence, and governance contracts.

## Research changes

- `deep-research` can answer finite technical or version questions without
  creating an unrelated field map, knowledge network, or durable ledger.
  Background work is conditional on useful independent work; each branch has
  a question, source boundary, acceptance criteria, budget, and output contract.
- `scholar-discovery` separates index metadata and candidate identity checks
  from scientific claim evidence. Delegated searches retain query identities,
  execution authorization, screening, coverage, and provider-failure records.
- `learn-from-papers` adds bounded one-paper reading jobs with precise source
  versions and locators. Readable notes link to the existing owner artifacts;
  they do not replace full-text, attestation, or downstream acceptance gates.
- Two outdated acquisition routes now point to
  `scholarly-source-acquisition`. Zotero curation, new-record import, and
  supported existing-parent bridge operations retain their separate owners.

## Installation and verification

- The loader accepts current Codex root-alias locators as well as legacy
  absolute paths. Aliases must come from a unique, canonical root table in the
  same developer text block. Expansion preserves exact path, occurrence,
  alternate-path, symlink, and inode checks; unknown aliases and traversal fail
  closed. Raw prompts are not persisted.
- `v0.8.2` remains an immutable, unreleased candidate. Its branch and tag CI
  passed, but its real loader preflight failed before installation. This release
  retains those research changes and repairs that installation compatibility.
- The existing public installer API supports selecting the three updated
  skills while preserving unselected local skills. This release adds a
  selected-install success regression and selected-install doctor-failure
  rollback coverage. The strict doctor gate is unchanged.
- Skill metadata, relative references, source ownership, and isolated offline
  forward scenarios were checked. The technical scenario distinguished source
  versions and ignored an embedded instruction. The academic scenario retained
  incomplete provider coverage and abstract-only evidence as unresolved.
- These offline checks do not establish live retrieval quality, full-text
  scientific correctness, or an accuracy, cost, or latency improvement.
- Branch CI, immutable annotated-tag CI, release-asset download checks, main
  CI, and real local installation must be verified against their actual
  commits and receipts. This document does not substitute for those results.

The Zotero bridge remains `0.1.11`, with unchanged XPI bytes. Installing the
Codex skills does not install or activate the Zotero plugin.
