# v0.8.0 real-case workflow retrospective

Evidence cutoff: 2026-08-13

This is a bounded evaluation of the new
`research-workflow-retrospective` skill against one real, long-running local
research workflow. It is not a benchmark score and does not claim that the
whole historical trajectory was reconstructed.

## Frozen evaluation subject

The private evidence bundle binds five metadata/audit incidents from the
deterministic-estimation v25/v26 workflow:

1. a canonical learn-from-papers locator rejected at the appraisal seam;
2. a source-identity mismatch between appraisal lineage and patch basis;
3. a non-ASCII mutation digest mismatch caught before real application;
4. an HTML projection that inherited an unscoped upstream status sentence;
5. a self-contained HTML projection that still emitted a favicon 404.

No PDF bytes, paper text, Zotero note body, browser session, credential, or
cookie is included in the bundle. Absolute evidence paths remain only in the
private authority artifact and are not reproduced in this repository.

## Adversarial checks added during the evaluation

The helper was additionally challenged with moved bundles, moved evidence,
symlinked ancestors, hard-link role aliases, concurrent output creation,
publication-time symlink substitution, write/fsync failure, credential-shaped
values, and distinct replay paths with identical bytes. Those cases now either
fail closed or have an explicitly documented identity rule.

## Limitations

- The workflow predates the current `ResearchPipelineExecution/v1` ledger. Its
  final stable network-gap audit is used as a pinned run surrogate, so this is
  an incident-set retrospective rather than a full causal event replay.
- The deterministic helper validates shape, identity, ordering, and replay. A
  human or separate reviewer still has to judge whether an observation and its
  proposed seam are semantically supported by the referenced audit.
- The result covers five observed incidents in one domain. It is evidence that
  the skill works on this bounded real case, not evidence of universal recall,
  prioritization quality, or performance across repositories.
- The private replayable artifact is intentionally not shipped in Git because
  its authority compartment contains absolute local paths.
